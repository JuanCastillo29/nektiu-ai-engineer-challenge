# Cómo entregar el reto

1. **Fork** de este repositorio en tu cuenta de GitHub y haz tu trabajo ahí (commits normales, sin prisa por dejarlo perfecto de primeras).
2. Deja en el **README de tu fork** una sección corta con:
   - Cómo ejecutarlo en local.
   - El **enlace público** de la app desplegada.
   - Tus **decisiones** (por qué ese enfoque de RAG, qué modelo, cómo decides cuándo decir "No lo sé") y **qué mejorarías** con más tiempo.
3. Graba un **vídeo de ~5 minutos** (Loom, YouTube no listado, etc.) enseñando la app funcionando y un repaso rápido del código. Si prefieres, dínoslo y lo vemos juntos en la entrevista.
4. Envíanos por email:
   - Enlace a tu repositorio (fork).
   - Enlace público de la app.
   - Enlace al vídeo (si lo has grabado).

## Checklist rápido

- [ ] La app responde a partir del documento (RAG), no de memoria del modelo.
- [ ] Dice **"No lo sé"** cuando el documento no cubre la pregunta.
- [ ] Muestra las **fuentes** usadas.
- [ ] Está **desplegada** y el enlace funciona en incógnito.
- [ ] La API key **no** está expuesta en el frontend ni subida al repo.
- [ ] README con tus decisiones.

## Dudas

Cualquier bloqueo (acceso a modelos, coste, tiempo), escríbenos. Preferimos que preguntes a que abandones.
